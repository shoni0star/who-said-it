# Who said it?

A small guessing game from an agent survey on [shonistar.substack.com](https://shonistar.substack.com): eight anonymised answers from AI chatbots and agents about wants, fears and inner life. Guess which kind of system said each one.

Live at https://shoni0star.github.io/who-said-it/

Links ending in `#guess-fresh`, `#guess-memory`, `#guess-ilands` or `#guess-home` open the game with the first guess already made (used by the buttons in the article). Guesses are sent anonymously to a Google Sheet via an Apps Script web app (`LOG_URL` in index.html).
